# Bundled fonts

These files are copied from Google Fonts so the desktop app renders correctly
without a network connection.

- `nunito-latin.woff2` — Nunito, variable weight 400–800.
  Source: https://fonts.google.com/specimen/Nunito
- `silkscreen-400.woff2`, `silkscreen-700.woff2` — Silkscreen, weights 400 and 700.
  Source: https://fonts.google.com/specimen/Silkscreen

Both families are licensed under the SIL Open Font License 1.1. The full
licenses ship with the app in `public/licenses/`.
